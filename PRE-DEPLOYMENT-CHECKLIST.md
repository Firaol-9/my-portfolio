# Pre-Deployment Checklist

Use this checklist before deploying your portfolio to GitHub Pages.

## ✅ Content Updates

- [ ] Update name in hero section
- [ ] Update location in hero section
- [ ] Update personal description
- [ ] Update education timeline with actual schools and years
- [ ] Add real achievement photos to `images/` folder
- [ ] Update achievement descriptions
- [ ] Update skills percentages if needed
- [ ] Add real project screenshots
- [ ] Update project descriptions
- [ ] Add actual project links (Live Demo and GitHub)
- [ ] Update school activities with real information
- [ ] Add real certificate images
- [ ] Update certificate information
- [ ] Add real book covers and reviews
- [ ] Update contact email in footer
- [ ] Add real social media links (GitHub, LinkedIn, Twitter)

## ✅ Technical Checks

- [ ] All images are in the `images/` folder
- [ ] All image paths in HTML are relative (start with `images/`)
- [ ] CSS file is in `css/` folder
- [ ] JavaScript file is in `js/` folder
- [ ] All file paths are relative (no absolute paths)
- [ ] Test website locally in browser
- [ ] Test dark/light mode toggle
- [ ] Test all navigation links
- [ ] Test modal image viewer
- [ ] Test responsive design on mobile
- [ ] Check for console errors (F12 → Console)
- [ ] Verify all images load correctly
- [ ] Test smooth scrolling
- [ ] Verify skill progress bars animate

## ✅ SEO & Meta Tags

- [ ] Update page title
- [ ] Update meta description
- [ ] Update meta keywords
- [ ] **IMPORTANT**: Update Open Graph URLs with your GitHub Pages URL
- [ ] **IMPORTANT**: Update Twitter Card URLs with your GitHub Pages URL
- [ ] Update social media preview image URLs
- [ ] Add favicon (optional: create a proper favicon.ico)

## ✅ Code Quality

- [ ] No broken links (all `href="#"` should be updated)
- [ ] All placeholder text replaced
- [ ] All images have descriptive alt text
- [ ] No console errors
- [ ] Code is properly formatted
- [ ] No commented-out code that shouldn't be there

## ✅ Files Ready for Git

- [ ] `.gitignore` file exists
- [ ] `README.md` is updated with your information
- [ ] `LICENSE` file exists (if you want to include it)
- [ ] No sensitive information in code
- [ ] No large unnecessary files

## ✅ GitHub Pages Specific

- [ ] Repository name is appropriate (will be part of URL)
- [ ] `index.html` is in root directory
- [ ] All assets (css, js, images) are in correct folders
- [ ] Test that relative paths work (open `index.html` directly in browser)

## 📝 After Deployment

- [ ] Update meta tag URLs in `index.html` with actual GitHub Pages URL
- [ ] Test website on GitHub Pages URL
- [ ] Share your portfolio link!

---

**Quick Test**: Open `index.html` directly in your browser. If everything works locally, it should work on GitHub Pages too!
